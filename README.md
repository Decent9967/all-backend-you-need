# ALL BACKEND YOU NEED · 后端工程治理知识框架（KB-01）

一个复刻 roadmap.sh 视觉与**知识组织方式**的交互式学习路线图（Next.js 单页应用）：
**三线结构长画布（中轴主线 + 两侧子线）+ 点击节点开详情抽屉 + 可勾选的学习进度**。

## 组织原则（对照 roadmap.sh 实测归纳，2026-08）

- **三线结构**：中轴主线只有 9 个亮黄里程碑（「后端是什么」→ D1…D7 → 「学完之后」），
  实线竖向串联；子内容分列主线两侧，蓝点线从里程碑辐射出去
- **主线上的毕业闸**：每域末尾的灰色「毕业自检」节点直接卡在主线上——
  不变量复述 + 检索题，过了闸才到下一站
- **域内子主题左右交替分列**：白框只包「同类成组」的选项（如「失败后的反应」），
  单概念直接作叶子挂线，不再整域一个大盒子
- **元内容降级**：五个本性 → 起点两侧的组框；本性推导 → 里程碑副题（「源 N1 · 对外提供服务」）；
  书单 → 域抽屉的资源区；自检题 → 各域毕业闸
- **紫色 = 进阶出口**（判断新实践 / 校准全景，分列终点两侧，
  对应 roadmap.sh 底部的 System Design / DevOps 区）

视觉按实测规格复刻：白底黑边圆角节点（rx=5、描边 2.7）、
亮黄 `#fdff00` 里程碑 / 淡黄 `#ffe599` 知识点 / 灰 `#dedede` 毕业闸 / 紫 `#4136d4` 出口、
Balsamiq Sans 手写体、蓝色 `#2b78e4` 3.5px 圆头连线（实线主线 / 点线分支）。

## 节点与抽屉内容

**一节点一页**（对齐 roadmap.sh 的 per-node content 模型）：

| 节点类型 | 数量 | 点击打开 |
|---|---|---|
| 知识点（域概念） | 84 | 专属笔记页：一句话定义 / 为什么需要它 / 关键点 / 常见误区 / 相关概念跳转（可跨域）/ 深入材料 |
| 里程碑（起点/七域/出口） | 9 | 起点：后端是什么 + 本性推导；域：该域完整面板（概念图/不变量/书单）；出口：判断流程 |
| 本性 N1–N5 | 5 | 本性说明 + 推导出的治理域（词条可跳转） |
| 毕业闸（灰，主线上） | 8 | 不变量复述（共 31 条）+ 检索题（D2/D6 附自测题，起点附三层模型题） |
| 三层 L1–L3 | 3 | 单层笔记页：定义 / 变化节奏 / 这层的例子 |
| 方法 01–04 | 4 | 单步页：说明 + 怎么练 |
| 出口（紫，终点两侧） | 2 | 决策流程图；校准 + 可展开的框架全景树 |

**范围边界登记表**（顶栏「范围边界」或 `#/scope`）：画布外独立页面，
结构化登记所有被评估过「不进入 / 暂缓」的知识项（名称 / 分类 / 处置原因 /
重新评估条件），防止后续维护者重复评估或未经评审加入。
数据在 `data/scope.ts`，恢复某项需在 PR 中说明其 revisit 条件已满足。

知识范围经过**两轮参照系**查漏补缺：

- 第一轮（路线图/清单类）：roadmap.sh 165 节点、OWASP API Top 10 / ASVS、
  中文后端社区高频主题 → 补入通信范式 / 消息语义 / 契约测试 / 分布式锁 /
  索引 / 复制分片 / outbox / 备份 / 限流 / 网关 / 优雅停机 / SLO /
  密码存储 / 会话管理 / 加密 / 灰度发布 等 16 项
- 第二轮（经典著作类）：《DDIA》→ 分布式事务与 Saga、流批管道；
  《Release It!》→ Steady State（数据生命周期）；《Google SRE》→ 故障复盘、
  容量规划；12-Factor → 无状态外置、环境一致性；microservices.io → Saga；
  Netflix 混沌工程 → 故障演练；ASVS V11 → 业务逻辑防滥用；
  roadmap.sh → HTTP 缓存语义——共 10 项、4 条新不变量
- 第三轮（D7 工程治理深挖，参照 Google SWE Book / Team Topologies / SRE 值班文化）：
  代码评审、代码所有权（CODEOWNERS）、第三方依赖管理、技术债管理、
  弃用与下线流程、康威定律与团队边界、值班与升级路径、文档与 Runbook——
  共 8 项、3 条新不变量；被否决/暂缓项全部进入范围边界登记表管理
- 第四轮（请求生命周期 + 生产事故清单倒推）：金额与精度（浮点算钱必错）、
  时间与时区（UTC 存储 / ISO 传输 / 展示层本地化）、定时任务与调度
  （幂等 + 互斥 + 错峰补偿）——共 3 项、3 条新不变量；另补 7 处笔记级要点
  （分页三件套、null 与缺字段语义、死锁三原则、数据范围权限、DB 账号三分离、
  N+1、主键选型）

刻意不含与暂缓项**统一由范围边界登记表管理**（`#/scope`），
不再散落在文档里——本框架只收「换语言不失效」的治理知识。

笔记数据在 `data/notes.ts`，按 `域ID|概念名` 索引；
新增概念只需在 `framework.ts` 加概念、在 `notes.ts` 补一条笔记（有校对脚本可对账缺失）。

「深入材料」已挂真实链接（**84 条笔记全部有材料**：114 条材料、102 个去重外链 +
2 条无公开电子版的书籍纯文本，链接来源：OWASP / Google SRE / martinfowler.com /
microservices.io / RFC / 12-Factor 中文版 / PoEAA / NIST / K8s / 官方文档与规范原文），
全部经 HTTP 探测确认可访问；`node scripts/check-material-urls.mjs`
可随时复查链接存活，`scripts/verify-related.mjs` 校验相关概念引用零悬空，
`scripts/verify-material-links.mjs` 对照浏览器渲染核对（配 Playwright 扫描）。

其中 D2（竞态时序）、D4（熔断状态机）的概念图在域面板内支持 **PPT 式分幕搭建**。

## 交互

- **站内搜索**：顶栏输入框（Ctrl/Cmd+K 聚焦），标题/域名/类型匹配，
  ↑↓ 选择、Enter 打开并定位到画布节点
- 点击节点 → 右侧抽屉（hash 路由 `#/d2-c0`，可刷新、可分享）；
  深链进入时节点自动滚到视口中央并蓝色高亮一瞬，无效链接归位画布并提示
- 节点右上角圈：勾选"已掌握"；进度只统计知识点/毕业闸/出口（`x / 93`），
  本性/三层/方法步骤是脚手架不计入；进度存 localStorage（自动剔除失效 id），可重置
- 抽屉内：上一个 / 下一个 / 标记已掌握；Esc 关闭；键盘 ← → 切换节点。
  「下一个」按子主题行的教学顺序走（与左右分列的几何位置无关），
  概念抽屉顶部有子主题面包屑
- 七个毕业闸统一为「不变量复述 + 一道检索题」，选错也显示正确项与解析
- 旧链接兼容：`#/natures` → N1，`#/layers` → L3，未知 → 画布
- 移动端：画布横向滑动查看全图（进入时提示一次），顶栏搜索折行

## 教学设计依据

- **分段原则（Mayer）**：抽屉内一题一焦点，分幕搭建控制节奏
- **双重编码（Paivio）**：每个治理域都有专属概念图，文字与视觉并行编码
- **测试效应（检索练习）**：毕业自检的检索题，选错也显示正确项与解析
- **先行组织者（Ausubel）**：脊柱 + 组框副标题先给全景与推导，再入节点细节

## 结构

```
app/                     外壳页面与全局样式（roadmap.sh 白板设计系统）
components/RoadmapCanvas 画布渲染层（中轴主线 + 两侧子线 + 毕业闸）
components/NodeDrawer    详情抽屉（按节点类型复用视图组件）
components/views/        抽屉复用的视图（起点/域/概念笔记/毕业自检/层/步骤/范围表/决策/综合/本性）
components/minis/        八张域概念图 + 框架全景树
data/roadmap.ts          画布数据（域内学习顺序 DOMAIN_ROWS、三线布局程序化生成）
data/notes.ts            节点笔记（84 概念 + 三层 + 四步，一节点一页；深入材料带真实外链）
data/scope.ts            范围边界登记表（不进入/暂缓项的结构化管理）
data/framework.ts        知识内容（本性、七域、概念、不变量、书单、校准）
data/sitemap.ts          自检题目与分幕讲解词
scripts/                 维护审计（概念↔笔记对账、材料链接存活/渲染核对）
```

增删概念只需改 `framework.ts`（并在 `roadmap.ts` 的 `DOMAIN_ROWS` 里给它一行归属），
画布布局自动重排；知识内容与画布结构、抽屉、进度全部数据驱动。
